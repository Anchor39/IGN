## Hyperspectral Dataset Download Links

- **CAVE Multispectral Image Database**  
  🔗 [https://cave.cs.columbia.edu/cave/repository](https://cave.cs.columbia.edu/cave/repository)  
  This dataset is provided by the Columbia Vision and Graphics Center. It contains a collection of high-quality indoor hyperspectral images acquired using a custom-built system. The data is widely used for spectral image reconstruction and enhancement research.

- **Harvard Vision Laboratory Hyperspectral Dataset**  
  🔗 [https://vision.seas.harvard.edu/hyperspec/](https://vision.seas.harvard.edu/hyperspec/)  
  This dataset includes outdoor and indoor hyperspectral images captured using a liquid crystal tunable filter (LCTF) camera system. It is frequently used for evaluating hyperspectral image processing and color constancy algorithms.

- **Hyperspectral Remote Sensing Scenes – Pavia Centre**  
  🔗 [https://www.ehu.eus/ccwintco/index.php/Hyperspectral_Remote_Sensing_Scenes#Pavia_Centre_scene](https://www.ehu.eus/ccwintco/index.php/Hyperspectral_Remote_Sensing_Scenes#Pavia_Centre_scene)  
  Provided by the University of the Basque Country, this dataset contains urban airborne hyperspectral imagery from the city of Pavia, Italy. It is commonly used for classification and remote sensing scene understanding.

- **Purdue University Multispec Hyperspectral Data (WDC Dataset)**  
  🔗 [https://engineering.purdue.edu/~biehl/MultiSpec/hyperspectral.html](https://engineering.purdue.edu/~biehl/MultiSpec/hyperspectral.html)  
  This page hosts a variety of hyperspectral datasets including the well-known *Washington DC Mall (WDC)* scene. The data is intended for use with the MultiSpec tool and is widely used in hyperspectral image classification tasks.
